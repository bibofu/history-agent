# M8.1 综合评估集验收

## 目标与结论

M8.1 将原有问答评估、人物交集复核和新增结构化查询题统一登记为 100 个带证据问题，覆盖人物时间线、事件、观点、人物交集、组织关系、观点冲突和拒答七类能力。`history-agent eval comprehensive` 会检查规模、类别下限、证据登记、问题 ID 和复核元数据。

2026-09-06 验收通过：100/100 个问题均登记页码证据或明确的拒答标签，七类样本均达到清单规定的下限，问题 ID 无重复。新增的 18 个结构化问题在当前研究数据库中全部返回指定源事件和 PDF 页码。

## 数据组成

| 来源 | 数量 | 用途 |
| --- | ---: | --- |
| `retrieval_questions.json` | 42 | 普通问答、事件、观点、时间线、交集、组织、冲突与拒答 |
| `person_intersections_independent.json` | 40 | 指定来源条目能否证明两人共同动作 |
| `structured_questions.json` | 18 | 12 个时间线查询、6 个组织关系查询 |
| **合计** | **100** | 统一由 `comprehensive_evaluation.json` 登记 |

类别分布为：时间线 22、人物交集 45、观点 8、事件 9、组织关系 9、冲突 4、拒答 3。同一普通问答可带多个标签，但综合统计只按一个核心类别计数；交集复核的每个来源页判断均视为一个独立的二元问题，按唯一 case ID 计数，不以人物组合与年份合并。

## 运行结果

```powershell
# 只审计综合清单，不依赖本地研究数据库
.\.venv\Scripts\history-agent.exe eval comprehensive

# 同时回归 18 个结构化查询
.\.venv\Scripts\history-agent.exe eval comprehensive --verify-structured

# 各组件仍可独立运行
.\.venv\Scripts\history-agent.exe eval retrieval --top-k 10
.\.venv\Scripts\history-agent.exe eval answers --top-k 10
.\.venv\Scripts\history-agent.exe eval intersections --case-set evals/person_intersections_independent.json
```

本次真实库结果：

- 综合清单：100 题，100 题有证据锚点或拒答标签，全部四项数据闸门通过；
- 结构化查询：18/18 命中指定源事件、文献和 PDF 页码；
- 混合检索：39 个可回答问题全部命中目标文献和年份，Recall@10=100%，MRR=0.8893；4 个新增冲突问题 Recall@10=100%；
- 确定性回答：42 题整体未通过旧 MVP 闸门，关键页命中率 69.23%、引用页文本一致率 99.03%、核心事实引用校验 100%、必要事实覆盖率 64.81%、拒答正确率 100%；
- 人物交集：40 个全正例中 TP=20、FN=20，Recall=50%；没有负例，不能评估误报率。

回答层低于旧 MVP 基线不是本轮回归导致的单一退化结论：当前时间线和交集问题已优先进入结构化路由，而 `eval answers` 仍按旧的页码级摘录式回答闸门统一评分。M8.1 保留这组失败作为后续评估分流和回答质量改进的基线，不通过改标签掩盖。

## 证据与限制

- 42 个普通问答由人工登记目标文献、PDF 页码和必要事实；3 个拒答题明确无证据目标；
- 18 个结构化问题从现有页码绑定的研究记录中人工选取，并用真实数据库逐条回归；它们验证可追溯性，不评价年度事件的重要性和完整性；
- 40 个交集标签由复核者确认，但按明确授权豁免逐案理由，`reason_quality=waived`。它们是不可审计的确认集，不应称为独立专家金标准；
- 当前冲突题验证同一官方党史叙述中明确呈现的意见分歧，尚未覆盖多来源互相矛盾的同一事实断言；
- 类别分布不均衡，交集题占比较高。后续扩充应优先增加负例、跨来源冲突和拒答边界，不应继续堆叠同类正例。
