# 结构化聊天路由验收（2026-09-05）

## 可用入口

现有聊天页面与 `POST /api/questions` 无需新增页面，可直接提交：

- 毛泽东在1949年有哪些经历
- 毛泽东与周恩来在1949年有哪些交集
- 周恩来在1942年至1943年参加过哪些会议

姓名和年份明确时，时间线/交集走研究库；普通观点问答继续走原混合检索。结构化路径不调用模型，也不会因数据库失败或零候选而回退到人名共现检索来“凑答案”。

## 验证结果

Ruff、mypy、120 项测试通过；前端 JavaScript 语法检查通过。新增聊天测试 19 项，覆盖路由不调用 RAG/LLM、规范事件实际证明来源、跨页引用范围、年份区间、会议类型、总数和截断提示、未知人物与附加条件拒绝、省略式追问澄清、缺库提示，以及普通观点问题不被时间线路由拦截。

真实库通过 FastAPI TestClient 验证，均 HTTP 200：

| 问题 | 路由 | 结果 |
| --- | --- | --- |
| 毛泽东在1949年有哪些经历 | structured_timeline | 603 条相关记录，top_k=2 展示前 2 条；毛年谱三卷 PDF 448 |
| 毛泽东与周恩来在1949年有哪些交集 | structured_intersection | v2 当前 11 条候选，展示前 2 条；毛年谱三卷 PDF 455、467 |
| 毛泽东和周恩来在1921年有哪些交集 | structured_intersection | 无候选，明确“不代表两人没有交集” |
| 毛泽东与周恩来在1949年2月有哪些交集 | structured_intersection | 不忽略月份条件，要求明确当前支持的年度查询 |

以上是 API/契约与前端语法验证，不冒充人工浏览器交互验收。原页抽样、漏报与样本范围见 `INTERSECTION_BASELINE.md`。

## 回答边界

有引用的结构化回答仍为 `partial`，交集角色统一待复核。时间线包含原文提及，不保证每条本人参与；展示按时间而非重要性排序，不能当作年度重要经历摘要。引用用实际共同动作证据，不用规范记录的任意另一成员证据。日期称为记录日期，并显示确定性，不把推定日期当作原页明文。

聊天最多显示前 12 条，尚不支持“下一页”或自动补全“那一年呢”的人物；复杂跨句参与名单仍有漏报。后续应扩充独立正负例和复杂句式召回，再发展带明确状态的多轮查询与分页。

后续 v3 更新：紧邻两句的明确活动与名单已经接入，完整证明不超过聊天的 420 字符引用预算。1956 年查询的 PDF 551 引文可同时显示会见叙述与周恩来所在名单；分组名单及非紧邻/跨页情况仍保守跳过。最新指标见 `INTERSECTION_BASELINE.md` 第三轮记录，上文保留为路由首次接入时的验收结果。

## 2026-09-07：恢复历史时期问题的原文综合路径

用户问题“毛泽东和周恩来在长征期间有哪些交集？”此前被结构化路由拦截，返回“请明确人物和年份”。检索层已有 `PERIOD_RANGES`，但聊天先要求四位数字年份，导致原本可检索的问题无法到达检索层。

现在先验证人物、单一已识别时期和剩余条件，再将时期问题交给混合检索与证据约束回答；年度问题继续走结构化候选。选择路径发生在共同动作查询之前，不依据候选为空或数据库错误触发回退。明确年份与时期混用、未知时期、月份、地点、否定、第三人和重复人物仍要求澄清。

交集引文现在优先保留两个人名附近的连续原文及前置事件语境，仍遵守 420 字符正文上限。此前党史第一卷 PDF 481 的引用窗口在关键人名处截断；不能仅因完整片段中两个人名共现，就认为交给模型的短引文也包含了完整证据。新窗口不改写原文、不把接近程度当作参与证据。`grounded-answer-v5` 明确要求具体互动和时期归属均由原文支持；检索交集结果标为 `partial`，摘录模式只称史料线索。

本地真实库验证（显式禁用 LLM）：原问题进入 `hybrid_rrf`，返回 8 条 PDF 引用，包括党史第一卷 PDF 481；`llm_status=disabled`，不再要求用户改写成数字年份。完整输出位于本地 `data/reports/long_march_chat_local.json`。该验证说明路由与证据链恢复，不代表交集完整性或生成答案质量验收通过；关键词与向量排名、交集规则及已有评估标签未改动。

Ruff、mypy 和 183 项测试通过；新增覆盖时期路由、约束保留、原问题 API 回归、引文窗口与提示词约束。DeepSeek 实际联网生成尚未验证：受限环境返回 `network_error`，外部验证申请因史料片段外发授权不足被自动审批拒绝。本记录不将失败降级计为模型成功。

## 2026-09-07：支持不限定年份的两人交集

“毛泽东和张国焘的交集”此前被结构化路由强制要求年份，尽管混合检索能够识别两人并召回同时出现的原文。现在先核验恰好两位已知且不同的人物及剩余约束；未给年份或时期的合法交集问题进入全库混合检索与证据约束综合。明确年份问题仍使用结构化候选，单一历史时期仍使用带时期范围的混合检索。

地点、月份、否定、未知第三人、重复人物、冲突年份或多个时期不会被静默忽略，仍返回澄清提示。该路径不把全库人名共现直接认定为已确认交集，最终提示词和页面限制继续要求原文支持具体互动。
