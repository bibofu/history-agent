# 模型辅助事件抽取契约基线

本文记录 M6.4 的本地可重复验证范围。它验证模型输出进入研究库前的安全边界，不把模拟响应冒充真实 DeepSeek 效果评估。

## 当前契约

- 输入对象必须是已有规则事件，并至少绑定一条本地文献证据；
- 每个事件发送给模型的全部证据正文合计硬限制为 1200 字符；
- DeepSeek 使用非思考模式和 JSON Output，一次只处理一个事件；
- 输出只能包含受控事件类型、行动原文、地点原文、机构原文、已登记人物提及、置信度和复核标记；
- 除事件类型外的事实字段必须是证据原文子串，仅允许忽略换行和空格；
- 模型不能修改日期、原始描述、文献、PDF 页码或证据关系；
- 未知/歧义人物、额外字段、非法枚举、非 JSON、空响应和截断响应均不能合并；
- 所有自动合并保持 `needs_review`，并保存模型、提示词、输入哈希、原始响应、Token 用量和前后快照；
- 同证据、同模型、同提示词版本默认幂等跳过，失败仅在显式要求时重试。

## 自动测试覆盖

`tests/test_model_extraction.py` 覆盖以下场景：

1. 有效 JSON 的安全合并、人物规范化、证据保留和调用审计；
2. 模型返回证据中不存在的地点时整次拒绝，事件不变；
3. 非 JSON 与 API 超时分别记录为 `invalid`、`failed`；
4. 所有成功、无效和失败结果均进入带优先级的复核队列；
5. 成功请求幂等跳过，不重复调用模型；
6. `--dry-run` 只选择候选，不调用 API、不写调用记录。
7. 多条证据合并送模时仍共享 1200 字符总预算，不按证据条数放大。

本地检查命令：

```powershell
& .\scripts\check.ps1
.\.venv\Scripts\history-agent.exe research enrich-events --dry-run --limit 5 --json
```

## 真实 DeepSeek 冒烟

2026-09-01 在获得明确资料外发授权后，从《周恩来年谱》选择 PDF 第 70、235 页各一条事件，使用 `deepseek-v4-pro` 和 `event-extraction-json-v1` 验证真实 JSON Output：

| 指标 | 结果 |
| --- | ---: |
| 运行 ID | `9a98aecee98f46e4aaad29382178a648` |
| 选中 / 成功 / 无效 / 失败 | 2 / 2 / 0 / 0 |
| 实际证据正文字符数 | 170、89 |
| Prompt / Completion / Total tokens | 815 / 192 / 1007 |
| 日期、描述、证据链接保持不变 | 2 / 2 |
| 进入 `needs_review` 和复核队列 | 2 / 2 |

模型为第 70 页识别出机构“中共中央”，为第 235 页识别出机构“共产国际”和原文明示的周恩来；两条事件类型均保持为通用 `activity`，没有被过度细分。相同参数再次执行时，结果为选中 0、跳过既有调用 2、使用 0 tokens，证明真实批处理幂等。

首次合并暴露了一个主体优先级问题：当年谱主体在原文中显式出现时，其 `mention_source` 是 `explicit`，旧逻辑错误地退回排序后的第一个人物作为名称前缀。复核检查在人工确认前发现了问题。修复后按“年谱主体”角色选择主体，并防止模型同名参与者覆盖该角色；第 235 页记录通过调用前快照恢复，修订保存在 `research_revisions`，原模型调用和错误合并快照均未删除。对应回归测试已加入自动测试集。

该冒烟只验证接口兼容、约束落库和审计闭环，不代表两条自动抽取已经成为已确认史实。
