# 跨来源事件合并基线

## 1. 目标

本基线验收 M6.5：从《周恩来年谱》《林彪年谱》的规则事件中发现同一历史事件的多来源记载，形成可查询的规范事件，同时不覆盖、不删除、不静默折叠任何来源差异。

## 2. 规则与分层

- 只比较不同文献中的事件，先按精确日或同月日期桶缩小候选；
- 评分综合日期、描述相似度与包含度、共同人物、年谱主体、机构、地点和事件类型；
- 默认候选最低分为 `0.70`，保守自动分层阈值为 `0.80`；
- `high_confidence` 还要求两条事件均精确到日、至少一条日期为原文明确年份，并满足更严格的文本/人物条件；
- 其余候选标记为 `uncertain/needs_review`，不得当作已确认史实。

重复执行结果为 `created=0`、`updated=0`、`skipped=69`、`deactivated=0`，说明相同输入幂等。

## 4. 完整性审计

- 15,393 条 `historical_events` 和 15,393 条 `event_evidence` 均保留；
- 每个规范事件至少关联两条证据，69 组均来自至少两份文献；
- 没有规范事件缺少证据；
- 没有源事件同时属于多个规范事件组；
- 139 个来源成员快照全部保存至少一条证据；
- 名称、日期原文、人物、地点、类型和描述等差异按来源保存在 `field_variants_json`；
- 人工确认、驳回和重新打开通过独立审计表记录，驳回不删除源记录。

## 5. 人工抽查结论

高分样本覆盖同一电报、会议、接见和行程在两部年谱中的不同叙述，来源页码均完整。待审样本中既有明显同一事件，也有“同日且人物大量重合、但行动不同”的疑似误配；后者没有自动确认，验证了人工队列的必要性。

当前 18 个 `high_confidence` 仍表示算法高置信候选，不等同于人工确认。后续时间线默认必须显示复核状态，并允许研究者按证据回到 PDF 页面复核。
