# 人物时间线查询基线

## 1. 目标

本基线验收 M6.6：按人物和年份查询结构化经历，合并同一事件的多来源记载，同时返回独立源事件、复核状态和可定位到 PDF 的证据。

## 2. 查询语义

- 默认返回 `confirmed`、`unreviewed` 和 `needs_review`，永不返回已驳回记录；
- 活跃规范事件折叠其成员源事件，避免同一事件重复显示；
- 规范事件被驳回后，成员源事件自动恢复；
- 当事件类型或复核状态筛选排除了规范事件时，不隐藏仍符合条件的成员源记录；
- 日期区间采用事件起止年份的相交语义，结果稳定升序排列；
- 所有记录至少包含一条文献、PDF 页码和短引文证据。

## 4. 自动化覆盖

契约测试覆盖：

- 规范事件与独立事件联合查询；
- 年份、事件类型和复核状态过滤；
- 分页总数与 `has_more`；
- 规范事件被驳回后的源记录恢复；
- 展示类型或复核状态差异下的源记录回退；
- 未知人物、非法复核状态和 API 研究年份边界；
- 参与者、来源事件 ID、文献标题、短引文和 PDF 页码返回。

当前时间线是结构化查询 API，尚未接入会话 Agent 的意图路由；该接入应在人物交集与关系查询具备后统一完成。
